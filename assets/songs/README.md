# Adding Songs

Place your `.mp3` files here:

```
assets/songs/song-01.mp3
assets/songs/song-02.mp3
assets/songs/song-03.mp3
assets/songs/song-04.mp3
assets/songs/song-05.mp3
```

Then update the `songs` array at the top of `app.js` with the correct
`title`, `artist`, and `audioUrl` for each file.

Use only music you own, have licensed, or that is royalty-free.
